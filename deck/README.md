## Detailed deck (deck_kit.py)

## What this deck covers

The system that exists in this repository, as built and measured. Unlike the
earlier pitch, it does not describe a target architecture. Every claim carries
a status chip saying where it came from:

| Chip | Meaning |
|---|---|
| MEASURED ON DEVICE | seen on the iQOO 15 (VaultLink sessions, capsules, KeyInfo, aapt2) |
| VERIFIED | host tests or tooling (flutter test, pytest, JCA interop, onnx verification) |
| BUILT - NOT HARDENED | implemented, not yet exercised on the device |
| OPEN GAP | known not to work yet |

## Where the numbers come from

- **iQOO 15 sessions:**
  - `SM8850`, StrongBox key level, valid ECDSA signature;
  - MiniLM on XNNPACK: 58 ms load benchmark, 113–137 ms in-query;
  - ≈2.0 s retrieval with StrongBox decrypt;
  - SmolLM2-1.7B Q4_K_M on the llama.cpp GPU backend at ≈10.5 tok/s
    end-to-end (163–198 tokens in 15.7–18.2 s);
  - 3 of 5 questions refused by the since-removed similarity gate.
- **Token offsets (slide 21):** `modelprep/dart_tokenizer_port.py` run on the
  exact chunks returned in the capsules.
- **Host verification:**
  - 236 Flutter tests, 66 Python tests, `flutter analyze` clean;
  - `aapt2 dump permissions` on both flavors;
  - JDK JCA ↔ Python interop;
  - `export_htp.py`: 305 nodes, cosine 1.000000.
- **Host ranking (0.6–0.8 ms / 1,000 × 384):** JIT on a desktop CPU, labelled
  as not a device figure.

**Do not upgrade the NPU claim.** QNN HTP is an open gap until the Model tab
on the device reads "QNN HTP verified".

## Design

- **Palette:** the `ui-ux-pro-max`
  "VPN & Privacy Tool" palette. Green means on-device or verified, red means it
  left the device or failed, amber means built but unproven, violet means
  roadmap.
- **Grid:** eyebrow → headline → standfirst → content → hairline + folio.
- **Type:** Aptos / Aptos Display / Consolas, which ship with Office.

## Checking a change

Text boxes don't clip in python-pptx, so overflowing copy silently overlaps
whatever is beneath it. Re-render and look at every slide:

```bash
powershell -Command "$app = New-Object -ComObject PowerPoint.Application; $p = $app.Presentations.Open('<abs path>\Vault_PocketRAG_Deck.pptx', $true, $false, $false); $p.Export('<abs path>\png', 'PNG', 1600, 900); $p.Close(); $app.Quit()"
```
